# v0.6 — 哑光龙脸、满幅魔法海面与轻量晶体

基于 main `dcc77c058bc38bd774038b80d76b97d2d32191c2`（已合并 PR #4）。不更换已认可的 Grab3D 模型，不改三命、分数、道具、实心八层砖阵、持球提示和横屏 HUD。

## 实施

龙的皮肤、角、须和鬃毛使用非金属哑光标准材质，roughness 0.90，无 clearcoat、transmission。只对从实际渲染反查的源模型眼部区域使用约 0.095 的低粗糙度；保留原有颜色分区。模型源文件及许可证不变。

以原造型为基准，绕两耳连线额外低头 30°，不是猜测一个屏幕 y 轴。轴在拟合空间约为 `(0.9397, 0, 0.3420)`；鼻子下移，颈部按原权重渐变。显示网格和碰撞采样都调用同一 `fitDragonPoint`，动态点头仍保留。镜头只缩紧安全取景，不改变输入映射。

海面的视觉半径由 12.8 扩至 256，径向网格近处密、远处疏，无原先圆盘边缘淡出。近处波面和碰撞法线仍来自原三组波；实际可碰撞半径限定 9.72，视觉扩展绝不扩大活动空间。去掉遮挡海面的外围地面/石块绘制；下半身仍按镜头自然显示。

井口为 10 根长条晶体，沿井缘衔接，端部共用轮廓、轻微交叠，中段宽度及切面高度不规则，呈共生晶环而非一圈独立鹅卵石。共享四种单次着色材质，保留大切面反光与透色层次，没有细描边。

## 性能回收

- 删除 `refraction.js`、`optics-rules.js` 及它们的分辨率缓存、渲染调用、采样 uniform、光学砖筛选和纹理读。
- 龙与井口都不再启用物理透射，默认游戏场景中 transmission 材质数量为零，因此不会隐式重画场景作透射背景。
- 删除井口每像素三次内部反弹／多平面求交。晶体井口只采样共享环境反射，没有每晶块屏幕缓存。
- 被六邻居完全包住的砖块保留在物理网格，仅从显示实例列表中剔除；任何邻居移除后下一次绘制即恢复。开放砖上的内部界面在昂贵光照之前丢弃。
- 不降低 DPR，不改球速，也不以降低游戏更新频率掩盖卡顿。副视继续低帧率缓存。

同一软件渲染器、1000×650 CSS 视口、相同 DPR、相同开局状态比较，初次着色器编译不用于帧率结论：稳定全双视图绘制约由 257 次降至 186 次（约 -28%），三角形提交由约 161 万降至约 95 万（约 -41%）；开局显示实例由 1,926 降至 812，但逻辑砖数仍为 1,926。后续细微造型调整可能改变少量三角形计数。此为渲染工作量核验，不是用户 GPU 的 FPS 承诺。

## 验证

`npm run check`；`npm test`；Chromium WebGL 回归（桌面、横屏、竖屏、旋转瞄准、Esc、防误释放、四方位持球、泡、失球/补发、解封动画）。新增测试检查耳轴不动点和鼻子下移、视觉海面与碰撞边界分离、昂贵折射路径确实删除、眼部单独粗糙度。
