# v0.4 — 外部神龙模型、26 块光学水晶与可读的持球状态

基于 main `0da0c2880e24567eb3d28635242688342a44fce9`（已合并 PR #2）。保留计分、三条命、道具和主副视角正交关系；不是重新实现游戏。

## 模型来源与边界

显示模型完全换成 Grab3D Chinese Dragon，页面：https://grab3d.com/models/creatures/chinese-dragon/ 。源模型和 LICENSE、manifest、provenance 一并入库。许可证 CC0-1.0；发布者注明 Meshy 生成基础网格、Blender 清理/缩放/贴图的 AI 辅助来源。不是本项目自己拼接的龙，也不冒称手工雕塑作品。

使用原版 light GLB，13,100,384 字节、399,999 三角形。通过坐标变换适配井体，整体横向轮廓约 17.04，井口内径 19.44。保留原始形体与纹理明暗，以自定义材质重映射为冷色晶雕效果。井下只展示封印空间中的部分，解封时取消裁切并整体升起。此资产没有骨骼动画；升空是整体路径动画，不声称独立骨骼飞行动作。

模型先加载、再允许发球。文件加载失败时显示错误并禁止发球，不回退到用户拒绝的程序化龙。碰撞代理从实际导入的顶点采样成 45×45 粗高度场；竖向细节与大范围轮廓比旧的椭圆额头更接近显示模型，但须、角的复杂三角形不逐个碰撞。

## 井口与材质

移除三阶细碎压顶、数百段装饰、叶形浮雕和密集嵌晶。井口只围 **26 个大晶块**，每块由闭合的七边截面及不规则分层切面构成，尺寸、倾角、高度和颜色存在受控差异。井身改为克制的透明光学套筒，避免和井口争抢形体。

四套共享的 MeshPhysicalMaterial：transmission 0.93、IOR 1.58、roughness 0.055、dispersion 0.34，结合厚度、吸收色、HDR 环境反射。额外的着色器近似三次晶体内部反射，增强大晶体内的转折和闪烁。这是“真实透射 + 程序化内部光学近似”，不是每个晶体的完整场景光线追踪。没有用线框或描边冒充切面。

保留上一版高质量分辨率和粒子档；此次增加主要集中在外部龙模型与少量井口晶体。实机 GPU 负载不可由 CI 帧率推断，角落继续显示真实渲染 FPS。

## 持球语义

飞行时仍使用真实物理位置和深度热色。持球时隐藏原球及其旧透视副本，在盾上方 1.05 单位处显示 **唯一的持球球核**。新球青色、捕获紫色，附带粗晶瓣和可见的发射三角。使用独立渲染顺序及关闭深度测试，让主视、侧视和背面都不会被盾或井口挡住。

主视图四个旋转方位均检查标记中心的真实渲染像素，而不只是检查 visible 属性。普通接球仍立即反弹；只有 bind 道具会抓球；点击/Space 显式释放，沿用“拖动途中捕获不能在同次松手误释放”的保护。

## 构图与符号

布局按圆形主体的纵横比拟合，不继续简单扩大主画面百分比。1440×900 时主视宽 954（约 66%），844×390 时约 490（58%），井口接近主视可用边界；侧视保留完整井体和更深的龙形。两画面统一冷色体系，副视图压低色彩。主副镜头方向保持正交。手机横屏分数放生命下方，避免遮住口沿，按钮保留可触及尺寸。

重开箭头改为一个连续、不自交的轮廓；播放三角、暂停、扬声器、扩盾箭头、沙漏、锁定、奖励晶核等采用准确的基础轮廓后再挤出倒角。锁扣与锁体相接，不悬空拼接。道具符号和发射标记分别面向实际渲染镜头。完整图标板检查正面轮廓，游戏内检查缩小后的辨识度。所有可见图标仍是真实模型，HTML 按钮只承担无障碍命中区。
